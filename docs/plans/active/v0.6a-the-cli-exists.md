**Goal:** `semlf` becomes a real installed command:
an executable zipapp on PATH, project configuration discovered by the core,
the `SEMLF_*` env rename, the installer fixes,
and an AGENTS.md snippet with no absolute path in it.

**Architecture:** Per ADR-0004:
the portable core stays one stdlib-only file and gains config discovery;
a separate `cli/semlf/` package owns routing and delegates every check to the core;
`install.py` builds the pyz and installs it as `~/.local/bin/semlf` —
**the executable pyz is itself the command; there is no separate shim**
(the umbrella has been amended to this topology).
Hooks keep invoking the bare core and are untouched except for config wiring inside `diagnose`.

**Tech Stack:** Python 3.9+ stdlib only in the core (`configparser` joins the allowlist);
`zipapp`/`zipfile`/`hashlib` in the installer (not the core); bun for the opencode adapter tests.

## Global Constraints

- The core (`scripts/check_linefeeds.py`) stays one file, Python 3.9 syntax, stdlib imports only.
  This plan adds exactly one import to it: `configparser`.
  Rule `100-project-map.md` and the zipapp proof notes must be updated to match (Task 9).
- The project config file is **`.semlf.ini`** (INI, section `[semlf]`), per ADR-0012 (written in Task 9).
- Precision over recall: a malformed, unreadable, or hostile config file is ignored entirely —
  never a crash, never a changed finding kind; only the `long` threshold can move.
- Exit codes are a contract:
  `--file` 0 clean / 1 violations, hook 2 only on `fused`, 64 usage, `--help`/`--version` 0.
  `semlf` must preserve them bit-for-bit by delegating to `core.main()`,
  and the delegation must save and restore **all** core invocation globals
  (`sys.argv` and `CLI_LONG_LIMIT`), in a `finally`.
- One version: `semlf` reports `check_linefeeds.__version__`; no second constant anywhere.
- Installer changes keep the existing idioms:
  same-directory staging with `os.replace`, `.bak` backup before any `--force` overwrite,
  refusal on divergence, and the `expanduser("~")` no-home guard with its monkeypatch test idiom
  (`tests/test_installer.py:586-648`).
- All prose in semantic linefeeds; every touched Markdown file passes
  `python3 scripts/check_linefeeds.py --file <file>` before commit.
- Full suite (`python3 -m pytest tests/ -q`) green before every commit;
  `bun test adapters/opencode/` green for Task 6.
- Commits: Conventional Commits, header ≤50 cols, body wrapped at 72,
  no attribution trailers, no task numbers or review rounds in messages.

```python
def load_config(start_dir):
    """Project configuration discovered from start_dir upward.

    The walk is physical: start_dir is resolved through symlinks once,
    then parents are taken lexically from the resolved path,
    so candidates, parents, and boundary checks share one representation.
    It stops at the first directory holding .semlf.ini or a .git entry
    (file or directory — worktrees use a file),
    because configuration must not leak across a repository boundary;
    in the directory holding both, the config wins,
    which is what permits a repository-root config.
    A start_dir that is not an existing directory returns {} without walking.
    Returns {"long_limit": int} for a valid file, else {} —
    a config file can tune the checker but must never break it.
    """
    cur = os.path.realpath(start_dir)
    if not os.path.isdir(cur):
        return {}
    found = None
    while True:
        candidate = os.path.join(cur, CONFIG_FILENAME)
        if os.path.isfile(candidate):
            found = candidate
            break
        if os.path.exists(os.path.join(cur, ".git")):
            break
        parent = os.path.dirname(cur)
        if parent == cur:
            break
        cur = parent
    if found is None:
        return {}
    parser = configparser.ConfigParser(interpolation=None)
    try:
        with open(found, encoding="utf-8") as fh:
            parser.read_file(fh)
        raw = parser.get("semlf", "long-limit", fallback=None)
    except (OSError, UnicodeDecodeError, configparser.Error):
        return {}
    if raw is None:
        return {}
    try:
        value = int(raw.strip())
    except ValueError:
        return {}
    return {"long_limit": value} if value >= 0 else {}
```

```python
_CONFIG_CACHE = {}


def active_long_limit(path=None):
    """Resolve the long-line advisory threshold; 0 disables it.

    Precedence: --long-limit flag, then $SEMLF_LONG_LINE,
    then the project config discovered from path's directory, then 120.
    A malformed or negative env value falls back to the next leg.
    Discovery results are memoized per resolved directory for one run;
    main() clears the memo at entry so each invocation sees the filesystem fresh.
    """
    if CLI_LONG_LIMIT is not None:
        return CLI_LONG_LIMIT
    raw = os.environ.get("SEMLF_LONG_LINE", "")
    if raw:
        try:
            value = int(raw)
            if value >= 0:
                return value
        except ValueError:
            pass
    if path is not None:
        key = os.path.realpath(os.path.dirname(os.path.abspath(path)))
        if key not in _CONFIG_CACHE:
            _CONFIG_CACHE[key] = load_config(key)
        cfg = _CONFIG_CACHE[key]
        if "long_limit" in cfg:
            return cfg["long_limit"]
    return DEFAULT_LONG_LINE
```

**Interfaces:**
- Consumes: `check_linefeeds` as `core` (import by module name; `scripts/` and `cli/` on `sys.path`).
- Produces: `semlf.cli.main(argv=None) -> int`.
  Surface: `semlf --version` prints `semlf {core.__version__}` and returns 0;
  `semlf --help`, `semlf -h`, `semlf check --help`, and `semlf check -h` print a `semlf`-named usage text and return 0;
  `semlf check` with zero paths prints a `semlf` usage error to stderr and returns 64;
  `semlf check PATH...` rewrites to `--file PATH...`;
  everything else is forwarded verbatim to `core.main()`,
  so `--file`, `--json`, `--long-limit`, `--hook`, and every exit code keep exact core parity.
  Delegation saves and restores `sys.argv` **and** `CLI_LONG_LIMIT` in a `finally`.
  In-process concurrent calls are not supported
  (the core parses from process globals; the CLI is a process-per-invocation tool),
  and the module docstring says so.
  Task 4's `__main__` stub calls this `main`.

The layering this file preserves:
the CLI supplies invocation and paths, the portable core supplies analysis.
Delegating to core.main() keeps flag parsing, output,
and the exit-code contract identical to the bare core by construction.

import check_linefeeds as core

USAGE = """usage: semlf [--version] [--help] <mode>

modes:
  check PATH...          check whole files (alias for --file PATH...)
  --file PATH...         check whole files; exit 1 on any fused/wrap violation
  --hook [claude|codex]  run as a PostToolUse hook reading JSON on stdin
options forwarded to the core: --json, --long-limit N
"""


def main(argv=None):
    argv = list(sys.argv[1:] if argv is None else argv)
    if argv == ["--version"]:
        print(f"semlf {core.__version__}")
        return 0
    if argv[:1] in (["--help"], ["-h"]) or argv[:2] in (["check", "--help"], ["check", "-h"]):
        print(USAGE, end="")
        return 0
    if argv == ["check"]:
        print("semlf check: give at least one PATH", file=sys.stderr)
        print(USAGE, end="", file=sys.stderr)
        return 64
    if argv and argv[0] == "check":
        argv = ["--file"] + argv[1:]
    saved_argv = sys.argv
    saved_limit = core.CLI_LONG_LIMIT
    sys.argv = ["semlf"] + argv
    try:
        core.main()
        return 0
    except SystemExit as exc:
        return exc.code if isinstance(exc.code, int) else 0
    finally:
        sys.argv = saved_argv
        core.CLI_LONG_LIMIT = saved_limit

```python
def build_pyz(dest):
    """Build and publish the semlf zipapp at dest, atomically and executable.

    The core is copied from scripts/ at build time,
    same rule as the packaging proof: a committed second copy would be a fork.
    The archive is staged in dest's own directory and published by os.replace,
    with the execute bit set before publication,
    so no observer ever sees a partial or non-runnable file at dest.
    """
    dest = Path(dest)
    dest.parent.mkdir(parents=True, exist_ok=True)
    with tempfile.TemporaryDirectory() as td:
        stage = Path(td) / "stage"
        (stage / "semlf").mkdir(parents=True)
        shutil.copy2(CHECKER, stage / CHECKER.name)
        for src in sorted(CLI_PKG.glob("*.py")):
            shutil.copy2(src, stage / "semlf" / src.name)
        (stage / "__main__.py").write_text(MAIN_STUB, encoding="utf-8")
        fd, tmp = tempfile.mkstemp(dir=str(dest.parent), prefix=dest.name)
        os.close(fd)
        try:
            zipapp.create_archive(stage, tmp, interpreter=PYZ_INTERPRETER)
            os.chmod(tmp, 0o755)
            os.replace(tmp, dest)
        except BaseException:
            os.unlink(tmp)
            raise


def pyz_state(path):
    """The installed-equality identity of a pyz, or None when unreadable.

    (member digest, executable bit, interpreter line):
    member contents because that is what runs,
    the execute bit and the shebang because without them nothing runs at all.
    zipapp embeds member timestamps, so they are deliberately excluded.
    """
    path = Path(path)
    try:
        first_line = path.read_bytes().split(b"\n", 1)[0]
        digest = hashlib.sha256()
        with zipfile.ZipFile(path) as archive:
            for name in sorted(archive.namelist()):
                digest.update(name.encode("utf-8"))
                digest.update(archive.read(name))
    except (OSError, zipfile.BadZipFile):
        return None
    return (digest.hexdigest(), os.access(path, os.X_OK), first_line)
```

    """Install the executable pyz as the semlf command.

    Publication is build_pyz's staged os.replace,
    so a destination appearing between classification and publication
    is replaced by a complete newer artifact rather than corrupted —

Cover, in the house style (Decision / Evidence / Alternatives rejected):
the config file is `.semlf.ini`, INI, section `[semlf]`,
discovered by the core with a physical (realpath-resolved) upward walk stopping at a `.git` boundary (file or directory);
precedence flag > env > config > default;

TOML (`tomllib` is 3.11+ per PEP 680, the core floor is 3.9,

strict JSON (no comments in a human-edited policy file,

hand-rolled JSONC stripping (a naive regex demonstrably corrupts legal values containing `//`,
and a correct string-aware scanner is parser code the precision contract should not own);
YAML (never in the stdlib);
CLI-side discovery (hooks and CI would disagree — ADR-0004 already places discovery in the core).
Note for the future: if the core floor ever rises to 3.11 (a v1.0-era question at the earliest),
