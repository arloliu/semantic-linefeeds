# Dev Tooling (Makefile, Ruff, pre-commit) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give this repo a standard `uv`-based Python dev workflow — lint, format, test, build, release — and bring the existing codebase into compliance with it.

**Architecture:** Ruff (lint + format) configured in `pyproject.toml` under a new `[dependency-groups] dev` group; a `Makefile` wraps every dev command through `uv run` so tool versions stay pinned to `uv.lock`; a dev-only `.pre-commit-config.yaml` runs Ruff plus the repo's own `semlf` self-check before each commit.

**Tech Stack:** `uv` (dependency + env management), `ruff` (lint/format), `pre-commit`, existing `pytest`/`bun test` suites.

## Global Constraints

- `scripts/check_linefeeds.py` stays stdlib-only, Python 3.9+, no new runtime import (`.agents/rules/100-project-map.md`). Formatting/lint fixes to this file are allowed; new imports are not.
- `requires-python = ">=3.9"` in `pyproject.toml` is unchanged; Ruff's `target-version` must match it.
- No PyPI publish automation.
`make release` builds locally and requires an explicit human confirmation before `uv publish` (ADR-0015).
- `python3 -m pytest tests/ -q` and `bun test adapters/opencode/` remain the two commands that define "tested" (`.agents/rules/300-testing.md`); new tooling wraps them, it does not replace them.
- Curated test content is exempt from mechanical reformatting: `tests/fixtures/` (per-language detector fixtures with inline `{fused}`/`{wrap}`/`{long}` markers) and `tests/extractor/` (byte-paired golden `in/`→`out/` files) are excluded from Ruff entirely — editing them is editing the thing under test, not the code style.
- Every Markdown file this plan's execution touches or creates must pass `python3 scripts/check_linefeeds.py --file <path>` with zero `fused`/`wrap` findings before commit (AGENTS.md self-hosting rule).

- [ ] **Step 1: Add the Ruff config block to `pyproject.toml`**

```toml

target-version = "py39"
line-length = 88
extend-exclude = ["tests/fixtures", "tests/extractor"]

[tool.ruff.lint]
select = ["E", "F", "W", "I", "B", "C4", "UP"]

[tool.ruff.lint.per-file-ignores]
```

`E501` (line-too-long) is off because this repo's own one-thought-per-line rule keeps long single sentences on one line in comments and docstrings rather than wrapping them mid-clause — a character-count lint would flag exactly what `semlf` protects.

### Task 2: `Makefile`

**Files:**
- Create: `Makefile`

**Interfaces:**
- Consumes: the `dev` dependency group from Task 1 (`uv run ruff`, `uv run pytest`, `uv run pre-commit`).
- Produces: `make lint`, `make format`, `make test`, `make selfcheck`, `make build`, `make release`, `make clean`, `make precommit` — Task 3 uses `make format`/`make lint`/`make test`; Task 4 uses `make precommit`.

- [ ] **Step 1: Write the Makefile**

```makefile
.DEFAULT_GOAL := help
.PHONY: help install lint format test selfcheck build release clean precommit

help: ## Show this help
	@grep -E '^[a-zA-Z_-]+:.*## ' $(MAKEFILE_LIST) | sed 's/:.*## /\t/'

install: ## Sync the dev environment (uv sync)
	uv sync

lint: ## Check lint rules, no fixes applied
	uv run ruff check .

format: ## Format and auto-fix
	uv run ruff format .
	uv run ruff check --fix .

test: ## Run the pytest suite, plus the opencode bun tests when bun is present
	uv run python3 -m pytest tests/ -q
	@if command -v bun >/dev/null 2>&1; then \
		bun test adapters/opencode/; \
	else \
		echo "bun not found, skipping adapters/opencode/ tests"; \
	fi

selfcheck: ## Run semlf's own checker over files changed since HEAD
	@files="$$(git diff --name-only --diff-filter=ACMR HEAD)"; \
	if [ -z "$$files" ]; then \
		echo "no changed files"; \
	else \
		python3 scripts/check_linefeeds.py --file $$files; \
	fi

build: ## Build sdist + wheel into dist/
	uv build

release: lint test build ## Build then publish to PyPI after manual confirmation
	@echo "About to publish $$(uv run python3 -c 'import sys; sys.path.insert(0, "scripts"); import check_linefeeds; print(check_linefeeds.__version__)') to PyPI."
	@read -p "Type the version above to confirm: " confirm && \
	version="$$(uv run python3 -c 'import sys; sys.path.insert(0, "scripts"); import check_linefeeds; print(check_linefeeds.__version__)')" && \
	if [ "$$confirm" = "$$version" ]; then \
		uv publish; \
	else \
		echo "Confirmation did not match, aborting."; exit 1; \
	fi

clean: ## Remove build artifacts
	rm -rf dist build *.egg-info cli/semlf.egg-info scripts/semlf.egg-info
	find . -name '__pycache__' -not -path './.git/*' -exec rm -rf {} +

precommit: ## Install the pre-commit git hook
	uv run pre-commit install
```

### Task 4: dev `.pre-commit-config.yaml`

**Files:**
- Create: `.pre-commit-config.yaml`

This is the repo's own dev-time pre-commit config — distinct from `.pre-commit-hooks.yaml`, which defines the hook this repo *ships* to downstream consumers and is not touched by this task.

**Interfaces:**
- Consumes: the `semlf` CLI entry point (`uv run semlf --staged`), already defined by `pyproject.toml`'s `[project.scripts]`.
- Consumes: `make precommit` from Task 2 to install the git hook.

- [ ] **Step 1: Write `.pre-commit-config.yaml`**

```yaml
repos:
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.0.0  # placeholder, resolved by `pre-commit autoupdate` in the next step
    hooks:
      - id: ruff-check
        args: [--fix]
      - id: ruff-format
  - repo: local
    hooks:
      - id: semlf
        name: semlf semantic linefeeds (self-check)
        entry: uv run semlf --staged
        language: system
        pass_filenames: false
```

- [ ] **Step 2: Resolve the pinned Ruff hook revision**

Run: `uv run pre-commit autoupdate --repo https://github.com/astral-sh/ruff-pre-commit`
Expected: rewrites the `rev: v0.0.0` placeholder in `.pre-commit-config.yaml` to the latest real tag (e.g. `v0.8.4`). Confirm with `git diff .pre-commit-config.yaml` that only the `rev:` line changed.

- [ ] **Step 3: Install and run the hook**

Run: `make precommit`
Expected: `pre-commit installed at .git/hooks/pre-commit`.

Run: `uv run pre-commit run --all-files`
Expected: all three hooks (`ruff-check`, `ruff-format`, `semlf`) PASS.
If `ruff-check`/`ruff-format` report anything, Task 3 was not fully clean — go back and fix rather than loosening this config.
The `semlf` hook runs `--staged`, which checks the git index — if nothing is staged yet in this working session, stage the current changes first (`git add -A`) so the hook has content to check, then unstage anything you don't intend to commit yet.
