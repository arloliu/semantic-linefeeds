# v0.6b — Git Modes: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL:
> Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `semlf` checks git snapshots:
`--staged` reads index blobs (what a commit would contain),
`--diff` and `--changed` read the worktree,
an `exclude` key in `.semlf.ini` filters discovery in hook mode and git modes,
and a `.pre-commit-hooks.yaml` runs `--staged` through the packaged CLI.

**Architecture:** Per ADR-0004 and rule 100:
the core gains the mode-agnostic pieces —
a shared source runner and the exclude filter beside the config it lives in —
while everything that knows git exists lives in one new CLI module,
`cli/semlf/providers.py`.
A provider turns one git snapshot into `(path, text)` pairs;
the runner turns pairs into reports and an exit code;
the two meet only in `cli/semlf/cli.py`'s routing.
The core never invokes git, and the providers never analyze text.

**Tech Stack:** Python 3.9+ stdlib only in the core (`fnmatch` joins the allowlist);
`subprocess` against the system `git` in the providers (CLI side, never the core);
pre-commit consumes the packaged CLI via `language: system`.

## Global Constraints

- The core (`scripts/check_linefeeds.py`) stays one file, Python 3.9 syntax, stdlib imports only.
  This plan adds exactly one import to it: `fnmatch`.
  Rule `100-project-map.md` must be updated to match (Task 8).
- The core never learns git exists:
  every `git` invocation lives in `cli/semlf/providers.py`,
  keeping the "copy one file, runs on bare python3" property
  and ADR-0011's implementation-agnostic contract intact.
- Exit codes are a contract, and the git modes join the `--file` shape:
  0 clean (including an empty snapshot), 1 on any fused/wrap violation **or** any source failure
  (git missing, not a repository, unreadable content), 64 usage;
  `long` findings never move an exit code anywhere.
- Excludes filter **discovery only**:
  hook mode and the git modes consult them;
  explicitly named `--file` / `check` paths are always checked.
  A malformed, unreadable, or hostile config fails open — never a crash,
  never a changed finding kind, never an exclusion the file did not clearly state.
  Excludes are user-directed like every suppression (ADR-0010's principle);
  an agent never adds one on its own authority.
- Exclude matching is case-sensitive on every platform (`fnmatch.fnmatchcase`):
  a rule that changes meaning between hosts would make the same commit clean on one machine and flagged on another.
- Providers report paths relative to the invoking directory
  and read text with the same tolerance as `--file` mode
  (`utf-8`, `errors="replace"`); source failures are loud (`SourceError`), never a silently shorter file list.
- Tests that build git repositories go through the `git()` helper added to `tests/conftest.py`
  (identity and signing pinned via `-c`), and skip cleanly where git is absent —
  same policy the bun suite already follows.
- All prose in semantic linefeeds; every touched Markdown file passes
  `python3 scripts/check_linefeeds.py --file <file>` before commit.
- Full suite (`python3 -m pytest tests/ -q`) green before every commit.
- Commits: Conventional Commits, header ≤50 cols, body wrapped at 72,
  no attribution trailers, no task numbers or review rounds in messages.

```python
def run_sources(sources, as_json=False):
    """Check (path, text) pairs and report exactly like --file mode.

    The one rendering and exit-code loop every checking mode shares:
    run_files feeds it disk reads,
    and the semlf git modes feed it snapshot content.
    Reading and read-error policy stay with the caller,
    because only the caller knows what a missing source means there.
    Exit 1 on any fused/wrap violation; long stays advisory.
    """
    violations = 0
    reports = []
    for path, text in sources:
        findings = diagnose(text, path)
        if findings:
            violations += sum(1 for d in findings if d["kind"] != "long")
            if as_json:
                reports.append(to_schema(path, findings))
            else:
                print(format_findings(findings, path, snippet=False))
    if as_json:
        print(json.dumps(reports, indent=2))
    return 1 if violations else 0


def run_files(paths, as_json=False):
    read_errors = 0
    pairs = []
    for path in paths:
        try:
            with open(path, encoding="utf-8", errors="replace") as f:
                pairs.append((path, f.read()))
        except OSError as e:
            print(f"semantic-linefeeds: cannot read {path}: {e}", file=sys.stderr)
            read_errors += 1
    rc = run_sources(pairs, as_json=as_json)
    return 1 if read_errors else rc
```

  (`None` when no config was found or the file was unusable).
  The dict may now carry two keys:
  `"long_limit"` (unchanged semantics)
  and `"exclude"`, a non-empty list of normalized pattern strings.
  Fail-open becomes **two-level**:
  file-level trouble (unreadable, undecodable, parser error) still returns `({}, None)`,
  while an invalid value now drops only its own key,
  so one bad `long-limit` no longer silences a good `exclude` beside it.
  Pattern normalization: backslashes become `/`,
  each non-blank line of the value is one pattern,
  surrounding whitespace and leading `/` are stripped,
  blank lines are dropped;
  a value with zero surviving patterns yields no `"exclude"` key.
- `load_config(start_dir) -> dict` keeps its public shape (`_config_and_root(...)[0]`),
  so every v0.6a caller and test is untouched.
- `_exclude_match(rel, patterns) -> bool` — the pure matcher over a `/`-normalized relative path.
  Grammar (recorded in ADR-0013, Task 8):
  a trailing `/` names folders —
  with an inner `/` the folder chain is anchored at the config root
  (`docs/generated/` excludes that tree and nothing else),
  without one the folder name excludes at any depth (`vendor/`);
  a pattern without a trailing `/` is an `fnmatch` glob —
  with a `/` it must match the whole relative path (`docs/*.md`),
  without one it may match any single path component (`*.gen.md`, `node_modules`).
  All matching is `fnmatch.fnmatchcase`: case-sensitive on every platform.
- `excluded(path) -> bool` — the discovery filter hook mode and the git modes call.
  Discovers the config from `path`'s directory
  (same entry as `active_long_limit`: `os.path.dirname(os.path.abspath(path))`),
  relativizes the **realpath** of `path` against the config's root,
  and returns `False` for a path outside that root,
  for a missing or unusable config, and for an empty pattern list.
  A false exclusion is a missed finding — the acceptable direction under precision over recall;
  a crash or a changed finding kind is not.

```python
def _config_and_root(start_dir):
    """(parsed config dict, real directory owning the config).

    ({}, None) when no config was found or the file was unusable.
    File-level trouble — unreadable, undecodable, parser error —
    drops the whole file;
    an invalid value drops only its own key,
    so one bad long-limit cannot silence a good exclude beside it.
    """
    cur = os.path.realpath(start_dir)
    if not os.path.isdir(cur):
        return {}, None
    found = None
    while True:
        candidate = os.path.join(cur, CONFIG_FILENAME)
        if os.path.isfile(candidate):
            found = candidate
            break
        if os.path.exists(os.path.join(cur, ".git")):
            break
        parent = os.path.dirname(cur)
        if parent == cur:
            break
        cur = parent
    if found is None:
        return {}, None
    parser = configparser.ConfigParser(interpolation=None)
    try:
        with open(found, encoding="utf-8") as fh:
            parser.read_file(fh)
        for option in list(parser.defaults()):
            parser.remove_option(configparser.DEFAULTSECT, option)
        raw_limit = parser.get("semlf", "long-limit", fallback=None)
        raw_exclude = parser.get("semlf", "exclude", fallback=None)
    except (OSError, UnicodeDecodeError, configparser.Error):
        return {}, None
    cfg = {}
    if raw_limit is not None:
        try:
            value = int(raw_limit.strip())
        except ValueError:
            value = -1
        if value >= 0:
            cfg["long_limit"] = value
    if raw_exclude is not None:
        patterns = []
        for line in raw_exclude.replace("\\", "/").splitlines():
            pattern = line.strip().lstrip("/")
            if pattern:
                patterns.append(pattern)
        if patterns:
            cfg["exclude"] = patterns
    return cfg, cur
```

```python
def _exclude_match(rel, patterns):
    """Whether a /-normalized relative path matches any exclude pattern.

    Grammar (ADR-0013): a trailing "/" names folders —
    with an inner "/" the chain is anchored at the config root,
    without one the folder name excludes at any depth.
    A pattern without a trailing "/" is an fnmatch glob —
    with a "/" it must match the whole relative path,
    without one it may match any single path component.
    fnmatchcase everywhere: a rule that changed meaning between
    platforms would make the same commit clean on one machine
    and flagged on another.
    """
    parts = rel.split("/")
    for pattern in patterns:
        if pattern.endswith("/"):
            target = pattern.rstrip("/")
            if "/" in target:
                if rel == target or rel.startswith(target + "/"):
                    return True
            elif target in parts[:-1]:
                return True
        elif "/" in pattern:
            if fnmatch.fnmatchcase(rel, pattern):
                return True
        elif any(fnmatch.fnmatchcase(part, pattern) for part in parts):
            return True
    return False


def excluded(path):
    """Whether the project config excludes path from discovery.

    Discovery-only: hook mode and the semlf git modes consult this
    filter; an explicitly named --file path never does — naming a path
    is the judgment call excludes exist to encode (ADR-0010's
    principle), and overriding it silently would hide a finding the
    user asked for.
    Fails open like every config path: no config, a config the parser
    rejects, or a path outside the config's tree excludes nothing.
    A false exclusion is a missed finding — the acceptable direction;
    a crash or a changed finding kind is not.
    """
    cfg, root = _config_and_root(os.path.dirname(os.path.abspath(path)))
    patterns = cfg.get("exclude")
    if not patterns or root is None:
        return False
    rel = os.path.relpath(os.path.realpath(path), root)
    rel = rel.replace(os.sep, "/").replace("\\", "/")
    if rel == "." or rel == ".." or rel.startswith("../"):
        return False
    return _exclude_match(rel, patterns)
```

  falling back to the absolute path when `relpath` cannot form one, as on a foreign Windows drive);

```python
"""Content providers for the semlf git modes.

The provider contract every mode shares:
a provider returns [(path, text), ...] pairs for one git snapshot,
where path is relative to the invoking directory
(so reports read naturally from wherever semlf ran)
and text is the full decoded content to check.
Selection, filtering, and reading all happen here;
analysis stays in the core (ADR-0004),
and the core never learns git exists.
Failures raise SourceError with a message ready for stderr:
a snapshot that cannot be enumerated or read is a loud stop,
never a silently shorter file list.
"""
import os
import subprocess

import check_linefeeds as core


class SourceError(Exception):
    """A git snapshot could not be enumerated or read."""


def _git(root, *args, input_bytes=None):
    try:
        proc = subprocess.run(["git", "-C", root, *args],
                              capture_output=True, input=input_bytes)
    except OSError as exc:
        raise SourceError(f"semlf: cannot run git: {exc}")
    if proc.returncode != 0:
        detail = proc.stderr.decode("utf-8", "replace").strip()
        raise SourceError(f"semlf: {detail or 'git exited %d' % proc.returncode}")
    return proc.stdout


def repo_root():
    """The enclosing repository's top-level directory, or a loud SourceError."""
    out = _git(os.getcwd(), "rev-parse", "--show-toplevel")
    return os.fsdecode(out).strip()


def _changed_names(root, *selector):
    """Root-relative changed paths for one git diff selector, deletions dropped."""
    out = _git(root, "diff", "--name-only", "-z", "--diff-filter=ACMR", *selector)
    return [os.fsdecode(name) for name in out.split(b"\0") if name]


def _head_or_empty_tree(root):
    """HEAD when it resolves, else the empty tree — an unborn branch diffs as all-new."""
    try:
        _git(root, "rev-parse", "--verify", "--quiet", "HEAD")
        return "HEAD"
    except SourceError:
        return os.fsdecode(
            _git(root, "hash-object", "-t", "tree", "--stdin", input_bytes=b"")
        ).strip()


def _checkable(rel):
    return core.is_markdown(rel) or core.lang_for_path(rel) is not None


def _display(root, rel):
    """Path as reported: relative to the invoking directory when possible."""
    absolute = os.path.join(root, rel)
    try:
        return os.path.relpath(absolute)
    except ValueError:
        return absolute


def _selected(root, names):
    """The checkable, non-excluded subset of a listing, with display paths."""
    kept = []
    for rel in names:
        if not _checkable(rel):
            continue
        if core.excluded(os.path.join(root, rel)):
            continue
        kept.append((rel, _display(root, rel)))
    return kept


def _worktree_sources(root, names):
    sources = []
    for rel, display in _selected(root, names):
        try:
            with open(os.path.join(root, rel),
                      encoding="utf-8", errors="replace") as fh:
                sources.append((display, fh.read()))
        except OSError as exc:
            raise SourceError(f"semlf: cannot read {display}: {exc}")
    return sources


def staged_sources(root):
    """Index versus HEAD; text is the index blob — what a commit would contain."""
    sources = []
    for rel, display in _selected(root, _changed_names(root, "--cached")):
        blob = _git(root, "show", ":" + rel)
        sources.append((display, blob.decode("utf-8", "replace")))
    return sources


def diff_sources(root):
    """Worktree versus index: unstaged changes, read from the worktree."""
    return _worktree_sources(root, _changed_names(root))


def changed_sources(root):
    """Worktree versus HEAD: staged and unstaged together, read from the worktree."""
    return _worktree_sources(root, _changed_names(root, _head_or_empty_tree(root)))
```

```python
    ap = argparse.ArgumentParser(prog="semlf", add_help=False)
    mode = ap.add_mutually_exclusive_group()

    try:

        return core.run_sources(sources, as_json=args.json)
    except providers.SourceError as exc:
        print(exc, file=sys.stderr)
        return 1
    finally:
        core.CLI_LONG_LIMIT = saved_limit
```
