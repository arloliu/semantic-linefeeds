# v0.5b Context-Aware Hooks and Suppression Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL:
> Use superpowers:subagent-driven-development (recommended),
> or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship ADR-0010 suppression directives and context-aware hooks in one change,
so the hooks see whole files with real line numbers exactly when users gain the escape hatch.

**Architecture:** The one-file core gains a directive grammar
(`parse_directive`, a trailing-carrier helper, one Markdown standalone regex),
`diagnose` collects suppressions while it walks the extractor stream and drops suppressed findings after the ownership filter,
and both hook entry points read a stable snapshot of the edited file,
map the payload to spans by ADR-0005's span-source rules,
and fall back to today's snippet mode whenever a mapping is not exact.

**Tech Stack:** Python 3.9+ stdlib only (`scripts/check_linefeeds.py`), pytest.

## Global Constraints

- The core stays one file: `scripts/check_linefeeds.py`, stdlib imports only.
- Precision over recall: a missed finding is acceptable, a false positive is a bug.
- ADR-0010 and ADR-0005 are the governing contracts; where this plan and an ADR disagree, the ADR wins.
- `tests/test_frozen_contract.py` must never be edited and must stay green:
  input without directives keeps byte-identical `check` output.
- `diagnose(text, path, spans=None)` keeps its signature; `check` stays the tuple projection.
- Directive names in prose must sit in code spans; bare tokens in plan or doc prose would self-suppress.
- Hook tests must not place target files under the platform temp directory or any `SKIP_DIRS` component
  (`skip_path` silently skips them, and a skipped path turns every hook assertion vacuous);
  use the `hook_dir` fixture defined in Task 5.
- Commit style: Conventional Commits, header ≤50 columns, body ≤72, no attribution trailers.
- Every touched Markdown file passes `python3 scripts/check_linefeeds.py --file <file>`.
- Validation before done: `python3 -m pytest tests/ -q`.

## Design invariants (from ADR-0010 and ADR-0005, binding for every task)

- Two carrier forms only: a **standalone** line whose extracted content is exactly one directive,
  and a **trailing** leader-marked tail ending the raw line.
- `WS` is ASCII space or horizontal tab; trailing `WS` is trimmed before carrier matching.
- A recognized name with any unknown argument token is **malformed and wholly inert**:
  it suppresses nothing, it is never stripped from the analyzed text,
  and the line stays ordinary prose, so its findings remain visible (ADR-0010's inertness clause).
  Only a **well-formed** standalone directive line is a paragraph boundary and leaves the stream.
- A recognized well-formed trailing carrier is one shared suffix,
  stripped from both the raw line and the extracted prose before every predicate;
  `long` measures the judged prefix.
  If the carrier suffix cannot be removed from both views, the directive is treated as unrecognized:
  nothing is recorded and nothing is stripped, so the two views never diverge.
- `semlf-ignore-next` targets exactly the next raw line, never skipping blanks.
- A line targeted twice suppresses the union of the two argument lists.
- Suppression applies after the ownership filter: detect → filter by ownership → drop suppressed → report.
- Excluded contexts (fences, frontmatter, tables, `<pre>`, indented code, licence-cut paragraphs,
  generated files where the core skips them, string literals) are never carriers, including `-next`.
- All recognition happens in `diagnose`, on the stream `without_license_text` has already filtered,
  so licence inertness holds by construction:
  the extractor marks candidate carriers by yielding them as prose, and records nothing itself.
- Hook span sources follow ADR-0005's table exactly:
  an Edit maps only when `new_string` occurs **exactly once** in a stable snapshot;
  `replace_all` edits take the snippet fallback this release (no preimage is available);
  a Write passes `content` with one whole-file span;
  a Codex file maps only when every hunk's post-state text locates exactly once;
  every other case is the retained snippet fallback.
- A snapshot is trusted only when it decodes as strict UTF-8,
  and when its identity — device, inode, size, nanosecond mtime — is unchanged across the read
  and still names the path afterward; otherwise the mapping degrades.
- A Codex hunk match must start and end on line boundaries;
  an interior-substring match is never exact.
  Every deleted line maps to a zero-width after-state boundary at its run's collapse point,
  so a deletion-only hunk can still own the finding it creates;
  a hunk-closing deletion collapses past the retained terminator, never before it.

```python
# ADR-0010: the suppression grammar.
# Longest name first, so `semlf-ignore-next` is one token,
# never `semlf-ignore` trailed by an unknown argument.
DIRECTIVE_KINDS = frozenset({"fused", "wrap", "long"})
DIRECTIVE_NAMES = ("semlf-ignore-next", "semlf-ignore")

# A recognized name with an unknown argument suppresses nothing at all;
# a sentinel keeps that state distinct from "not a directive".
MALFORMED = object()


def parse_directive(content):
    """Parse content that should be exactly one directive.

    Returns (offset, kinds) for a well-formed directive,
    where offset 0 targets the carrier's own line and 1 the next raw line,
    MALFORMED for a recognized name with any unknown argument,
    and None when content is not a directive at all.
    WS is ASCII space or horizontal tab, per the contract.
    """
    tokens = [t for t in re.split(r"[ \t]+", content) if t]
    if not tokens or tokens[0] not in DIRECTIVE_NAMES:
        return None
    args = tokens[1:]
    if any(a not in DIRECTIVE_KINDS for a in args):
        return MALFORMED
    offset = 1 if tokens[0] == "semlf-ignore-next" else 0
    return offset, (frozenset(args) or DIRECTIVE_KINDS)
```

```python
# A trailing HTML-comment carrier: the rightmost comment, ending the line.
# [^<>] keeps the match inside one comment, so an earlier comment stays prose.
MD_TRAILING_RE = re.compile(r"<!--([^<>]*)-->[ \t]*$")


def trailing_carrier(line, is_md, lang):
    """The parsed directive, judged prefix, and carrier suffix, or None.

    ADR-0010: the carrier is the rightmost leader-to-line-end suffix
    after the end trim, and a malformed tail is wholly inert —
    it neither suppresses nor is stripped from the judged text.
    The returned carrier is the exact suffix the caller must also
    strip from the extracted prose, so raw and prose never diverge.
    """
    trimmed = line.rstrip(" \t")
    if is_md:
        m = MD_TRAILING_RE.search(trimmed)
        if not m:
            return None
        parsed = parse_directive(m.group(1))
        if parsed is None or parsed is MALFORMED:
            return None
        return parsed, trimmed[:m.start()].rstrip(" \t"), trimmed[m.start():]
    if lang is None or not lang.line:
        return None
    idx = trimmed.rfind(lang.line)
    if idx <= 0:
        return None  # no marker, or only the comment's own leading marker
    parsed = parse_directive(trimmed[idx + len(lang.line):])
    if parsed is None or parsed is MALFORMED:
        return None
    return parsed, trimmed[:idx].rstrip(" \t"), trimmed[idx:]
```

```python
def _identity(stat):
    """The four fields that must agree for a snapshot to be one file."""
    return (stat.st_dev, stat.st_ino, stat.st_size, stat.st_mtime_ns)


def _read_snapshot(path):
    """One stable snapshot of path, or None when it cannot be trusted.

    Strict decoding: a replacement character would shift offsets while
    the mapping still claimed to be exact.  The descriptor is stat'd
    before and after the read (an in-place change moves size or mtime),
    and the path is stat'd after it (an atomic replacement moves the
    inode), so bytes from a file the path no longer names degrade
    instead of being labeled exact.
    """
    try:
        with open(path, encoding="utf-8") as f:
            before = os.fstat(f.fileno())
            text = f.read()
            after = os.fstat(f.fileno())
        final = os.stat(path)
    except (OSError, UnicodeDecodeError):
        return None
    if not (_identity(before) == _identity(after) == _identity(final)):
        return None
    return text


def _locate_unique(text, needle):
    """The span of needle's only occurrence, or None.

    Overlapping repeats count as ambiguous, so the second search starts
    one code point after the first hit rather than after its end.
    """
    if not needle:
        return None
    first = text.find(needle)
    if first < 0 or text.find(needle, first + 1) >= 0:
        return None
    return {"start": first, "end": first + len(needle)}
```

**Behavior (ADR-0005: "Match full hunk context against a stable post-state; else addition-run fallback"):**
- A hunk's post-state text is its context and added lines joined with `"\n"`;
  deleted lines are omitted from the text but keep their position in the hunk.
- Context lines are patch lines that are not `+`, `-`, `@@`, or `*** ` lines;
  one leading space is stripped when present (the apply_patch context prefix).
- Every hunk of a file must locate exactly once via `_locate_hunk`,
  whose match must start at offset 0 or after a newline
  and end at end-of-text or before one —
  a hunk body appearing only inside a longer unchanged line is not that hunk.
  Interior-substring occurrences neither match nor count toward ambiguity.
- The spans passed to `diagnose`: each added line's range,
  plus one zero-width `{"at": ...}` boundary per deleted line,
  at the offset where the run's neighbors now meet.
  Consecutive deletions repeat their run's collapse point;
  the duplicates are harmless to normalization and touching.
  The collapse point is the start of the following post-state line;
  when the deletion closes the hunk it sits **past** the retained terminator
  (`located.end + 1` when a newline follows, `located.end` only at true end-of-text),
  because a boundary before the terminator would touch ownership on the retained line
  and over-own an unchanged finding there.
  ADR-0005 requires the zero-width form:
  deleting a line can create a finding no added range represents.
- An all-context hunk contributes no spans but must still locate (it anchors the mapping).
- Any failure — unreadable or untrusted snapshot, unlocatable or ambiguous hunk,
  empty post-state text — degrades that one file to `check` over the joined added runs, `snippet=True`.

```python
def hunks_by_file(patch):
    """Map file path -> hunks, each a list of (kind, text) lines.

    kind is "add", "ctx", or "del".  A deleted line contributes no
    post-state text but keeps its position, because its collapse point
    is a changed boundary ADR-0005 requires as a zero-width span.
    Context lines carry the apply_patch space prefix when present;
    one is stripped.  A `*** Move to:` rename re-keys the entry to the
    destination path.
    """
    files = {}
    current = None
    hunk = None
    for line in patch.splitlines():
        m = PATCH_FILE_RE.match(line)
        if m:
            current = m.group(1).strip()
            files.setdefault(current, [])
            hunk = None
            continue
        mv = PATCH_MOVE_RE.match(line)
        if mv and current is not None:
            files[mv.group(1).strip()] = files.pop(current)
            current = mv.group(1).strip()
            hunk = None
            continue
        if line.startswith("*** "):
            current = None
            hunk = None
            continue
        if current is None:
            continue
        if line.startswith("@@"):
            hunk = None
            continue
        if hunk is None:
            hunk = []
            files[current].append(hunk)
        if line.startswith("+"):
            hunk.append(("add", line[1:]))
        elif line.startswith("-"):
            hunk.append(("del", ""))
        else:
            hunk.append(("ctx", line[1:] if line.startswith(" ") else line))
    return {p: [h for h in hunks if h] for p, hunks in files.items()
            if any(hunks)}


def _locate_hunk(text, body):
    """The unique line-bounded occurrence of a hunk body, or None.

    A hunk is whole lines, so its match must start at offset 0 or after
    a newline and end at end-of-text or before one; a body embedded in a
    longer unchanged line is not this hunk, and such interior hits
    neither match nor make the real one ambiguous.
    """
    if not body:
        return None
    found = None
    start = 0
    while True:
        idx = text.find(body, start)
        if idx < 0:
            return found
        end = idx + len(body)
        if ((idx == 0 or text[idx - 1] == "\n")
                and (end == len(text) or text[end] == "\n")):
            if found is not None:
                return None
            found = {"start": idx, "end": end}
        start = idx + 1
```
