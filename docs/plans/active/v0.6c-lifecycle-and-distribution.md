# v0.6c — Lifecycle and Distribution: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL:
> Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An install has a full lifecycle:
`--uninstall` removes every managed artifact including the Codex skill (ADR-0006's deferral),
`semlf doctor` replays a synthetic payload end to end and collects ADR-0011's platform evidence,
a provenance manifest lets an untouched older release upgrade while a hand edit still refuses,
`--auto` detects which agents are present before installing,
`install_cli --force` claims its backup slot exclusively instead of overwriting the only copy,
and `pipx` / `uv tool` can install `semlf` straight from the repository URL,
with the zipapp retained for air-gapped and mirrored installs.

**Architecture:** The split follows what each verb needs, not where ADR-0004's list happened to put it.
Install, uninstall, and status stay in `scripts/install.py`,
because the adapter payloads they copy live only in the checkout.
Doctor and the manifest reader ship inside the artifact (`cli/semlf/doctor.py`, `cli/semlf/manifest.py`),
because doctor must diagnose machines that have only the artifact.
`install.py` imports the manifest module from `cli/` —
one implementation, read by both sides, shipped in the pyz and the wheel.
The core is not touched by this slice:
no new imports, no new functions, only the version-string bump at release.

**Tech Stack:** Python 3.9+ stdlib throughout;
`setuptools` declarative packaging in `pyproject.toml` for the pipx/uv channel;
`subprocess` for doctor's end-to-end replays (CLI side, never the core).

## Global Constraints

- The core (`scripts/check_linefeeds.py`) is off-limits to this slice, except for the `__version__` bump in the release task.
  Doctor consumes only the core's existing public surface
  (`load_config`, `active_long_limit`, `__version__`).
- Exit codes stay a contract.
  `install.py`: 0 success or no-op, 1 refusal or error, 64 usage —
  uninstall and auto-detection join the same shape.
  `semlf doctor`: 0 when every check passes or only advisories fire,
  1 when any check fails, 64 usage.
- **Fail toward refusal, never toward overwrite.**
  A missing, unreadable, or malformed manifest downgrades an artifact to "unrecorded",
  which keeps today's behavior: refuse divergence without `--force`.
  Provenance can only make the installer *more* willing to replace bytes it can prove it wrote,
  never less careful with bytes it cannot.
- **A provenance record proves three things or nothing.**
  An entry is valid only as `{path: str, sha256: 64 lowercase hex, version: str}`,
  it classifies a destination only when the recorded path and the queried path resolve identically,
  and its digest is computed from the bytes the installer itself staged or rendered —
  never by re-reading a mutable destination after publication.
  Anything less is `unrecorded`.
  Classification never follows a link:
  every check `lstat`s first, and only a regular file can be `managed`.
- **Provenance state is one file per artifact, so writers cannot interfere.**
  Each of the four fixed artifact names owns
  `$XDG_STATE_HOME/semlf/artifacts/<name>.json`;
  `record` atomically replaces one file, `forget` unlinks one file,
  and no operation ever rewrites another artifact's state —
  a stale writer can neither drop a sibling entry nor resurrect a forgotten one.
  A `record` and a `forget` racing on the *same* name is last-writer-wins,
  which is acceptable because each outcome is exactly one of the two racing intents.
  Readers take one snapshot per run and classify against that snapshot,
  and unknown artifact names are never read at all.
- **State files are read defensively, everywhere, and the guard is total.**
  Every lifecycle read — manifest entries, `hooks.json`, every artifact hashed —
  goes through one no-follow open primitive:
  `lstat` first, only a non-symlink regular file within the size bound qualifies,
  the open carries `O_NOFOLLOW` (where the platform has it) plus `O_NONBLOCK`
  so a FIFO can neither be followed into nor block the open,
  an `fstat` on the descriptor re-checks regular-file identity,
  and bytes are read **from that descriptor**, never by reopening the path.
  Parsing catches `RecursionError` alongside `OSError` and `ValueError`,
  and entry validation rejects empty and NUL-containing paths,
  so no bounded byte sequence and no schema-valid string can raise a traceback.
  What the guard rejects is a named refusal or failed check, never a hang.
- **The concurrency boundary is same-user and stated, not silently assumed.**
  A local actor mutating lifecycle paths concurrently is out of scope by the umbrella's ruling —
  that boundary cannot be held from inside the installer —
  so the plan does not chase lstat-to-open or preflight-to-apply races beyond what the primitive gives for free,
  and on platforms without `O_NOFOLLOW` the symlink guarantee is the `lstat` gate alone.
  Every claim of the form "never follows", "never edits", "never executes"
  is scoped to the state observed at classification time;
  ADR-0014 records the boundary and this scope explicitly.
- **Ownership is structural, never substring.**
  The installer's Codex hook entry is recognized by the enclosing shape and the exact command:
  matcher `apply_patch`, hook `type` `command`,
  and a command that POSIX-shlex-parses to
  `["python3", <path whose basename is exactly check_linefeeds.py>, "--hook", "codex"]`.
  Install-time updates, status, uninstall, and doctor all use the one predicate.
  Anything that does not match every element is foreign and is preserved —
  values unchanged through the JSON round-trip;
  only formatting normalizes to the installer's own two-space style,
  the same way install's merge already rewrites the file.
- **Uninstall is preflight-then-apply.**
  A read-only preflight classifies every selected target first;
  one inadmissible target refuses the whole request with nothing touched.
  Apply-phase failures stop at the first error and report what was and was not removed.
  A home that cannot resolve refuses the mode that needs it, mirroring install.
  A symlink, FIFO, directory, or unreadable or undecodable file is inadmissible at any target.
  `--force` overrides that **only for installer-owned single-file artifacts**
  (the skill, the two opencode files, the cli),
  and only for objects a single `unlink` removes —
  it unlinks a link itself, never its target,
  and a **directory stays refusal-only under every flag**,
  because removing a tree is never the one-file operation this verb performs.
  The shared files — `hooks.json` and the AGENTS.md target — are refusal-only:
  no flag ever deletes or unlinks a shared path,
  and owned content inside them is removed only as a semantic edit of a healthy regular file,
  whose backup slot (`<name>.bak`) preflight has verified is absent or a regular file —
  a symlink there would be written through, so it refuses the request instead.
- **Dry-run mutates nothing, anywhere.**
  Every write — artifact bytes, manifest entries, hook JSON, snippet text,
  directory removal — sits behind one `if not dry` boundary per operation.
  Dry-run performs the same classification and refusal checks as a real run
  and exits with the same codes.
- Deletion is refused for content the installer cannot identify:
  uninstall removes a file only when its bytes match the current rendering or the manifest digest,
  and requires `--force` otherwise —
  removing a hand-edited copy must be as deliberate as overwriting one.
- Backups are exclusive.
  The `--force` backup path claims `semlf.bak` with `O_CREAT | O_EXCL`,
  refusing when anything already sits there —
  a regular file, or a symlink, which is never followed.
  Local actors with write access to `~/.local/bin` stay out of scope by the umbrella's ruling.
- The installer never edits foreign content:
  uninstalling the Codex hook removes only entries whose command names `check_linefeeds.py`,
  and uninstalling a snippet block removes only what sits between the sentinels.
- Every installer test runs against an isolated `HOME`, `CODEX_HOME`, `XDG_CONFIG_HOME`,
  **and `XDG_STATE_HOME`** —
  a test that writes the developer's real manifest is a test bug.
- The packaging metadata must not fork the core:
  the wheel carries `scripts/check_linefeeds.py` as the `check_linefeeds` module
  and `cli/semlf/` as the `semlf` package, both straight from their repository locations.
- All prose in semantic linefeeds; every touched Markdown file passes
  `python3 scripts/check_linefeeds.py --file <file>` before commit.
- Full suite (`python3 -m pytest tests/ -q`) green before every commit;
  `sh docs/proofs/zipapp-packaging/verify.sh` green before the release task closes.
- Commits: Conventional Commits, header ≤50 cols, body wrapped at 72,
  no attribution trailers, no task numbers or review rounds in messages.

  per the umbrella's ruling on the v0.6a finding.
- Uninstall is preflight-then-apply and removes only what it can identify
  (current rendering, or manifest-managed), requires `--force` otherwise,
  never deletes shared files (`hooks.json`, the AGENTS.md target),
  and never touches `semlf.bak`.
- Doctor replays payloads end to end rather than checking file existence,
  certifies an installed hook in both directions or fails it,
  and its platform lines are the evidence stream ADR-0011's gate reads.
- Alternatives rejected:
  a per-artifact manifest beside each install (litter, partial-removal states);
  moving install/uninstall into `semlf` (the write-verbs belong beside the payloads they copy,
  and a pipx-installed `semlf` has no checkout to copy from).

```python
def _exclusive_backup(src, bak):
    """Copy src's bytes to bak, claiming the slot exclusively.

    O_EXCL is the point: the backup slot is claimed atomically,
    so a concurrent double --force cannot overwrite the only copy
    of a hand-patched artifact,
    and a pre-existing symlink at bak is refused, never followed.
    The cleanup covers every step including copystat:
    a failure at any point releases the slot,
    so a retry never finds it occupied by a half-made backup.
    """
    fd = os.open(str(bak), os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
    try:
        with os.fdopen(fd, "wb") as fh:
            fh.write(Path(src).read_bytes())
        shutil.copystat(src, bak)
    except BaseException:
        os.unlink(bak)
        raise
```

### Task 2: The provenance manifest and managed upgrade

A manifest records what the installer last published,
so an untouched older release upgrades without `--force`
while a hand edit still refuses.
Identity is the sha256 of the published bytes,
computed from the staged artifact or rendered payload **before** publication —
never by re-reading the destination afterward,
because a destination is mutable and a concurrent writer's bytes must not be blessed.
It is deliberately not the pyz member digest:
provenance asks what was *published*, not what would be *rebuilt*.
A record classifies a destination only when the recorded path and the queried path resolve identically,
so a stale entry from a moved home can never authorize action somewhere else.
The module also carries the structural Codex-hook ownership predicate,
because provenance and ownership are the same question —
"is this the thing the installer wrote?" —
and install, status, uninstall, and doctor must all answer it identically.

**Files:**

- Create: `cli/semlf/manifest.py`
- Modify: `scripts/install.py`
  (`install_cli`, `install_codex_skill`, `install_opencode`, new `core_version`, `sys.path` insert)
- Test: `tests/test_installer.py`, `tests/test_manifest.py`

**Interfaces:**

- Produces: `manifest.KNOWN` — the fixed artifact-name tuple
  `("cli", "codex-skill", "opencode-plugin", "opencode-checker")`;
  nothing outside it is ever read, written, or reported.
- Produces: `manifest.artifact_state_path(name) -> Path | None` —
  `$XDG_STATE_HOME/semlf/artifacts/<name>.json`,
  default under `~/.local/state`, `None` when no home resolves.
- Produces: `manifest.read_regular_bytes(path, limit)` — the no-follow snapshot primitive
  (`lstat`, `O_NOFOLLOW | O_NONBLOCK` open, `fstat` re-check, bounded fd read),
  returning the bytes or `None` for **any** trouble —
  and `manifest.read_state_json(path, limit=65536)` on top of it,
  returning parsed JSON or `None`, with `RecursionError` treated as trouble.
  Every lifecycle JSON read and every artifact hash goes through these;
  Task 3 and Task 5 read `hooks.json` through `read_state_json` too,
  and this task rewires `install_codex`'s and `status()`'s own `hooks.json` reads onto it
  (a `None` result takes the same refusal or `unreadable` path their current parse failures already take).
- Produces: `artifact_state_path(name)` raising `ValueError` for any name outside `KNOWN`,
  so `record`, `forget`, `classify`, and `load` can never touch a path outside the four fixed state files —
  no rogue names, no separator traversal.
- Produces: `manifest.load() -> dict` —
  one entry per `KNOWN` name whose state file holds a **valid** entry
  `{"path": str, "sha256": 64 lowercase hex, "version": str}`;
  everything else is silently absent.
- Produces: `manifest.record(name, path, version, sha256)` / `manifest.forget(name)` —
  `record` atomically replaces the one state file, `forget` unlinks it;
  no operation touches another artifact's state,
  so concurrent writers cannot drop or resurrect each other's entries.
  The digest is **supplied by the caller** from bytes it staged or rendered itself.
- Produces: `manifest.classify_entry(entry, path) -> str` —
  `"managed"` only when the entry is valid,
  `path` is a non-symlink regular file (`lstat` first, `S_ISREG`),
  `entry["path"]` and `path` resolve to the same location (`os.path.realpath` equality),
  and its bytes hash to the recorded digest;
  `"edited"` when identity holds but the bytes differ;
  `"unrecorded"` for everything else, including any read failure.
- Produces: `manifest.classify(name, path) -> str` —
  `classify_entry(load().get(name), path)`, the one-shot convenience wrapper.
- Produces: `manifest.parse_managed_codex_hook(matcher, hook) -> list | None` —
  the structural ownership predicate over the enclosing shape and the command:
  the parsed argv only when `matcher == "apply_patch"`,
  `hook` is a dict with `type == "command"`,
  and `hook["command"]` is a string that `shlex.split`s (POSIX rules) to exactly
  `["python3", <path whose basename == "check_linefeeds.py">, "--hook", "codex"]`;
  `None` for anything else, including unparsable quoting and non-string input.
- Produces: the four destination helpers
  (`codex_home`, `opencode_plugins_dir`, `codex_skill_dest`, `cli_bin_dest`)
  **move verbatim** from `install.py` into `manifest.py`;
  `install.py` imports them back under the same names,
  so its call sites and the existing tests stay unchanged
  while doctor gains the same destinations without duplication.
- Produces: `core_version() -> str` in `install.py` —
  the repo core's `__version__`, parsed textually.
- Produces: `guarded_pyz_state(dest)` in `install.py` —
  `(pyz identity, bytes)` from one guarded snapshot of a destination, or `None`;
  the only way any code takes a pyz identity from a live destination
  (`install_cli`'s decision, adoption, and `status()`'s cli report all consume it).
- Consumed by: Task 3 (`forget`, `classify`, `parse_managed_codex_hook`, `read_state_json`)
  and Task 5 (`load`, `classify_entry`, `parse_managed_codex_hook`, `read_state_json`,
  the destination helpers).
- The Codex `hooks.json` is never manifest-tracked:
  it is a shared merged file whose entry is identified structurally instead.

```python
"""Install identity: provenance, ownership, and destinations (ADR-0014).

One JSON file per artifact records what the installer last published:
$XDG_STATE_HOME/semlf/artifacts/<name>.json holding
{"path", "sha256", "version"}.
A record proves three things or nothing —
schema, path identity, and a digest of bytes the installer itself staged —
and every failure degrades to "unrecorded", which keeps the strict path:
provenance can make the installer more willing to replace bytes
it can prove it wrote, never less careful with bytes it cannot.
One file per artifact is the concurrency ruling:
record replaces one file, forget unlinks one file,
so no writer can drop or resurrect another artifact's state,
and a same-name race resolves to one of the two racing intents.
"""
import hashlib
import json
import os
import re
import shlex
import stat
import tempfile
from pathlib import Path

KNOWN = ("cli", "codex-skill", "opencode-plugin", "opencode-checker")

_HEX64_RE = re.compile(r"^[0-9a-f]{64}$")


def _state_base():
    """$XDG_STATE_HOME/semlf, or ~/.local/state/semlf, or None.

    Same home guard as the destination helpers below.
    """
    if os.environ.get("XDG_STATE_HOME"):
        return Path(os.environ["XDG_STATE_HOME"]) / "semlf"
    home = os.path.expanduser("~")
    if home == "~":
        return None
    return Path(home) / ".local" / "state" / "semlf"


def artifact_state_path(name):
    if name not in KNOWN:
        raise ValueError(f"unknown artifact name: {name!r}")
    base = _state_base()
    return None if base is None else base / "artifacts" / (name + ".json")


def sha256_bytes(data):
    return hashlib.sha256(data).hexdigest()


def read_regular_bytes(path, limit):
    """The bytes of a non-symlink regular file, or None for any trouble.

    The one no-follow snapshot primitive every lifecycle read and hash
    goes through: lstat first — only a non-symlink regular file within
    the size bound qualifies — then an open carrying O_NOFOLLOW (where
    the platform has it) plus O_NONBLOCK so a FIFO swapped in after the
    lstat can neither be followed into nor block the open, an fstat
    re-check of regular-file identity on the descriptor, and a bounded
    read from that descriptor — the path is never reopened.
    Where O_NOFOLLOW does not exist the lstat gate is the whole symlink
    guard; the residual window is same-user concurrency, out of scope
    by ADR-0014's stated boundary.
    """
    path = str(path)
    try:
        st = os.lstat(path)
        if not stat.S_ISREG(st.st_mode) or st.st_size > limit:
            return None
        flags = (os.O_RDONLY
                 | getattr(os, "O_NOFOLLOW", 0)
                 | getattr(os, "O_NONBLOCK", 0))
        fd = os.open(path, flags)
        try:
            if not stat.S_ISREG(os.fstat(fd).st_mode):
                return None
            chunks = []
            remaining = limit + 1
            while remaining > 0:
                chunk = os.read(fd, remaining)
                if not chunk:
                    break
                chunks.append(chunk)
                remaining -= len(chunk)
            data = b"".join(chunks)
        finally:
            os.close(fd)
        if len(data) > limit:
            return None
        return data
    except OSError:
        return None


def read_state_json(path, limit=65536):
    """Parsed JSON from a state file, or None for any trouble at all.

    Total over every bounded byte sequence: RecursionError from a
    deeply nested value is trouble like any other, never a traceback.
    """
    data = read_regular_bytes(path, limit)
    if data is None:
        return None
    try:
        return json.loads(data.decode("utf-8"))
    except (ValueError, RecursionError):
        return None


def _valid_entry(entry):
    # An empty or NUL-carrying path would make the os.path functions
    # raise instead of classify; schema validity must imply totality.
    return (isinstance(entry, dict)
            and isinstance(entry.get("path"), str)
            and entry["path"] != ""
            and "\x00" not in entry["path"]
            and isinstance(entry.get("sha256"), str)
            and _HEX64_RE.match(entry["sha256"]) is not None
            and isinstance(entry.get("version"), str))


def load():
    """One snapshot: every KNOWN artifact whose state file holds a valid entry."""
    snapshot = {}
    for name in KNOWN:
        path = artifact_state_path(name)
        if path is None:
            continue
        entry = read_state_json(path)
        if _valid_entry(entry):
            snapshot[name] = entry
    return snapshot


def record(name, path, version, sha256):
    """Record a publication whose digest the caller computed pre-publish.

    The digest parameter is the contract: provenance is established from
    the bytes the installer staged or rendered, never by re-reading a
    mutable destination that a concurrent writer may have replaced.
    """
    state = artifact_state_path(name)
    if state is None:
        return
    state.parent.mkdir(parents=True, exist_ok=True)
    text = json.dumps({"path": str(path), "sha256": sha256,
                       "version": version}, indent=2) + "\n"
    fd, tmp = tempfile.mkstemp(dir=str(state.parent), prefix=state.name)
    try:
        with os.fdopen(fd, "w", encoding="utf-8") as fh:
            fh.write(text)
        os.replace(tmp, state)
    except BaseException:
        os.unlink(tmp)
        raise


def forget(name):
    state = artifact_state_path(name)
    if state is None:
        return
    try:
        os.unlink(state)
    except FileNotFoundError:
        pass


CLASSIFY_LIMIT = 16 * 1024 * 1024  # a pyz or skill is far below this


def classify_entry(entry, path):
    """'managed', 'edited', or 'unrecorded' for the bytes at path.

    Managed needs the full proof, checked in this order: a valid entry,
    bytes taken through the no-follow snapshot primitive (so a symlink,
    FIFO, or over-limit file is never followed, hung on, or hashed —
    and is ruled out before any path resolution), the recorded path and
    the queried path resolving identically, and a digest match.
    Identity without a digest match is 'edited'; anything else,
    including any read or resolution failure, is 'unrecorded'.
    """
    if not _valid_entry(entry):
        return "unrecorded"
    path = str(path)
    data = read_regular_bytes(path, CLASSIFY_LIMIT)
    if data is None:
        return "unrecorded"
    try:
        if os.path.realpath(path) != os.path.realpath(entry["path"]):
            return "unrecorded"
    except (OSError, ValueError):
        return "unrecorded"
    return "managed" if sha256_bytes(data) == entry["sha256"] else "edited"


def classify(name, path):
    return classify_entry(load().get(name), path)


def parse_managed_codex_hook(matcher, hook):
    """The parsed argv when (matcher, hook) is the entry this kit installs.

    Structural over the enclosing shape and the exact command the
    installer writes: matcher apply_patch, hook type command, and a
    command whose four POSIX-shlex tokens are python3, a path whose
    basename is exactly check_linefeeds.py, --hook, codex.
    Anything less — a foreign launcher, a lookalike basename, another
    matcher or hook type, extra arguments, unparsable quoting, a
    non-string — is None, and callers must preserve it untouched.
    """
    if matcher != "apply_patch" or not isinstance(hook, dict):
        return None
    if hook.get("type") != "command" or not isinstance(hook.get("command"), str):
        return None
    try:
        argv = shlex.split(hook["command"])
    except ValueError:
        return None
    if (len(argv) == 4
            and argv[0] == "python3"
            and os.path.basename(argv[1]) == "check_linefeeds.py"
            and argv[2:] == ["--hook", "codex"]):
        return argv
    return None
```

```python
            if not force and not managed:
                print(f"refusing to overwrite {dest}: its content differs "
                      "from this build (hand-patched or older version). "
                      "re-run with --force to replace it.", file=sys.stderr)
                return 1
            divergent = True
```

This task owns the **final** shape of `install_cli`'s decision and publish flow —
Task 1's branch is an intermediate state, and this supersedes it,
so the two tasks cannot drift apart on the dry-run or error paths:

```python

        if not divergent:
            print(f"would install {dest}")
        elif managed:
            print(f"would upgrade {dest} (managed install)")
        else:

                      "exists; move it aside and re-run.", file=sys.stderr)

            print(f"would back up and replace {dest}")

        digest = manifest.sha256_bytes(staged.read_bytes())

                _exclusive_backup(dest, bak)

                return 1

                print(f"cannot back up {dest} to {bak}: {exc}",
                      file=sys.stderr)
                return 1

            os.replace(staged, dest)
        elif not _publish_new(staged, dest):

                  file=sys.stderr)

        raise

    _path_note(dest)
```

Three properties this final branch pins:
dry-run and real runs share one classification,
so a managed upgrade succeeds in both even with an occupied backup slot
(the slot matters only on the unmanaged `--force` path);
a backup `OSError` is a normal exit-1 diagnostic with the staged file cleaned up,
never a traceback;
and the digest comes from the staged file **before** publication —
if a concurrent writer replaces `dest` between publish and `record`,
the state file holds *our* digest and the foreign bytes classify as `edited` —
refusal, the safe direction.

Adoption — blessing an exact-current copy that predates the manifest —
consumes the same guarded snapshot the decision above already took,
so the identity check and the recorded digest come from the same bytes

The verb is one entry point with two phases.
**Preflight** builds a list of planned actions by classifying every selected target read-only;
any target it cannot admit produces a refusal instead of an action.
One or more refusals print all together on stderr,
and the whole request exits 1 with nothing touched — no file, no hook entry, no manifest byte.
**Apply** executes the planned actions only when preflight admitted everything,
stops at the first unexpected `OSError`,
reports what was and was not removed, and exits 1 on such a stop.
Dry-run runs the identical preflight and refusal logic,
then `_apply` prints each planned action as `[dry-run] would remove {path}`
and returns without executing any of them.

```python
def uninstall(args):
    """Preflight every selected target, then apply only if all admit."""
    actions, refusals = [], []
    if args.codex:
        _plan_codex_hook(actions, refusals)
        _plan_file("codex skill", codex_skill_dest(), codex_skill_body().encode("utf-8"),
                   "codex-skill", args.force, actions, refusals, prune_parent=True)
    if args.opencode:
        _plan_opencode(actions, refusals, args.force)
    if args.cli:
        _plan_cli(actions, refusals, args.force)
    if args.agentsmd is not None:
        _plan_agentsmd(Path(args.agentsmd), actions, refusals)
    for refusal in refusals:
        print(refusal, file=sys.stderr)
    if refusals:
        return 1
    return _apply(actions, args.dry_run)
```

Every planner shares one signature convention —
it appends `(label, apply_callable)` pairs to `actions`
and human-readable refusal strings to `refusals` —
and one destination rule:
the planner resolves its own destination helper first,
and a `None` destination (no home resolves) refuses that mode,
mirroring install's own no-home refusals.
Classification, hashing, and removal never follow a symlink:
`lstat` decides what a path is before anything opens it.

- **Codex hook** (`_plan_codex_hook(actions, refusals)`):
  read `hooks.json` through `manifest.read_state_json` —
  a missing file plans the no-op note (`codex: not installed`),
  while a symlink, FIFO, oversized, unreadable, or unparsable file is a refusal
  (the guarded reader cannot distinguish these; the refusal message says so
  and points at repairing or removing the file by hand).
  Preflight also `lstat`s `hooks.json.bak`:
  anything there that is not absent or a regular file refuses the request,
  because the rewrite's backup copy would otherwise write through it.
  Owned means `manifest.parse_managed_codex_hook(block.get("matcher"), h)` is not `None`;
  every other block and entry — unknown shapes, non-string commands, lookalike text,
  foreign matchers — is preserved:
  values unchanged through the JSON round-trip,
  formatting normalized to the installer's two-space style,
  exactly as install's own merge already rewrites the file.
  A block left with an empty `hooks` list is dropped;
  a block with no `hooks` key or other metadata is left as it stands.
  The planned action rewrites the file through `atomic_write`, never deletes it.
- **Single-file artifacts**
  (`_plan_file(label, dest, reference_bytes, name, force, actions, refusals, prune_parent=False)`):
  used for the skill and both opencode files,
  with `OPENCODE_PLUGIN` / `CHECKER` as reference bodies
  and `codex-skill` / `opencode-plugin` / `opencode-checker` as manifest names.
  Outcomes by `lstat`:
  absent → no-op note;
  a symlink or FIFO refuses without `--force`,
  and with `--force` the planned action unlinks the object itself, never a target;
  a directory refuses under **every** flag —
  removing a tree is never this verb's one-file unlink;
  an unreadable regular file refuses without `--force`;
  a regular file whose bytes equal the reference body,
  or whose `manifest.classify(name, dest)` is `managed`,
  plans removal plus `manifest.forget(name)`;
  anything else refuses without `--force` naming the divergence.
  With `prune_parent=True` the action also prunes a now-empty parent directory
  (`if not any(parent.iterdir())`, wrapped in `try/except OSError`) —
  used by the skill for `semantic-linefeeds/`.
- **The cli** (`_plan_cli(actions, refusals, force)`):
  the same `_plan_file` rules with one extra admit —
  identity also holds when a `guarded_pyz_state(dest)` snapshot matches `pyz_state` of a fresh temp build
  (a `None` snapshot follows the single-file refusal rules;
  the live destination is never handed to `pyz_state` —
  only the fresh temporary build may use it directly).
  A lingering `semlf.bak` is mentioned in a note but never touched:
  it is the user's backup, not ours.
- **agentsmd** (`_plan_agentsmd(target, actions, refusals)`):
  `lstat` first — a symlink or non-regular target is a refusal
  (this file is user-owned, so `--force` does not override here);
  the same `lstat` check covers the target's `.bak` sibling,
  which the rewrite's backup copy would otherwise write through;
  an unreadable or undecodable file is a refusal with the hand-repair message;
  then install's sentinel validation
  (one open, one close, in order — anything else refuses the same way);
  a file without the block plans a no-op note.
  The planned action splices the block out:

```python
    pre = text.split(SENTINEL_OPEN)[0]
    post = text.split(SENTINEL_CLOSE, 1)[1].lstrip("\n")
    new = pre.rstrip("\n")
    if new and post:
        new = new + "\n\n" + post
    elif post:
        new = post
    elif new:
        new = new + "\n"
    atomic_write(target, new, dry)
```

The file is never deleted, even when the block was its only content.

The apply phase is the only place mutations happen,
and each action's writes — the unlink, the `atomic_write`, the `manifest.forget`,
the parent prune — execute together behind `_apply`'s one `if dry` gate,
so a dry-run can never touch the manifest or any target.
Apply executes what preflight admitted **without revalidating it**:
a target mutated between the two phases is same-user concurrency,
out of scope by ADR-0014's stated boundary,
and every preservation claim in this task is scoped to the state preflight observed.

```python
"""semlf doctor — replay reality, report evidence (ADR-0014).

Every check either exercises the installed artifact end to end
or reports evidence a human (or ADR-0011's gate) needs verbatim.
Checks fail loudly; environment observations only warn.
Exit 0 when every check passes, 1 when any fails, 64 on usage.
"""
import json
import os
import platform
import shlex
import shutil
import stat
import subprocess
import sys

import check_linefeeds as core
from semlf import manifest

BAD_PAYLOAD = json.dumps({"tool_input": {
    "file_path": "/x/a.md",
    "new_string": "One sentence. Two sentence.\n"}})
GOOD_PAYLOAD = json.dumps({"tool_input": {
    "file_path": "/x/a.md",
    "new_string": "One sentence.\n"}})
CODEX_PAYLOAD = json.dumps({
    "hook_event_name": "PostToolUse",
    "tool_name": "apply_patch",
    "tool_input": {"command": (
        "*** Begin Patch\n*** Update File: pkg/doc.go\n@@\n"
        "+// Package cache provides caches. A cache\n"
        "+// holds entries.\n*** End Patch")},
    "tool_response": {"output": "Done"}})
CODEX_CLEAN_PAYLOAD = json.dumps({
    "hook_event_name": "PostToolUse",
    "tool_name": "apply_patch",
    "tool_input": {"command": (
        "*** Begin Patch\n*** Update File: pkg/doc.go\n@@\n"
        "+// Package cache provides caches.\n*** End Patch")},
    "tool_response": {"output": "Done"}})


def _artifact_command(artifact):
    """How to invoke the running artifact as a child process."""
    if artifact and os.path.isfile(artifact) and os.access(artifact, os.X_OK):
        return [artifact]
    return [sys.executable, artifact]


def _pipe(cmd, payload):
    """(exit code, stderr text), or None when the process cannot start."""
    try:
        proc = subprocess.run(cmd, input=payload.encode("utf-8"),
                              capture_output=True, timeout=60)
    except (OSError, subprocess.TimeoutExpired):
        return None
    return proc.returncode, proc.stderr.decode("utf-8", "replace")


def _expected_destinations():
    """Each known artifact's current expected location, or None entries.

    The same helpers the installer publishes with (they live in the
    manifest module), so provenance is always judged against where the
    artifact would be installed today — never against a record's own
    claim about itself.
    """
    opencode_dir = manifest.opencode_plugins_dir()
    return {
        "cli": manifest.cli_bin_dest(),
        "codex-skill": manifest.codex_skill_dest(),
        "opencode-plugin":
            None if opencode_dir is None else opencode_dir / "semantic-linefeeds.ts",
        "opencode-checker":
            None if opencode_dir is None else opencode_dir / "check_linefeeds.py",
    }


def _long_limit_line():
    """The limit in force for the invoking directory, with its source.

    active_long_limit consults project config only when it is handed a
    path (it starts discovery from that path's directory), so doctor
    passes a synthetic child of the cwd — the same resolution any file
    checked here would get.  The source label re-walks the precedence
    legs with the core's own validity rule: an invalid environment
    value falls through exactly as the core treats it.
    """
    probe = os.path.join(os.getcwd(), "doctor-probe.md")
    value = core.active_long_limit(probe)
    env_raw = os.environ.get("SEMLF_LONG_LINE")
    env_valid = False
    if env_raw is not None:
        try:
            env_valid = int(env_raw) >= 0
        except ValueError:
            env_valid = False
    if env_valid:
        source = "$SEMLF_LONG_LINE"
    elif "long_limit" in core.load_config(os.getcwd()):
        source = ".semlf.ini"
    else:
        source = "default"
    return f"long-limit: {value} ({source})"


def run(argv, artifact=None):
    if argv:
        print("semlf doctor takes no arguments", file=sys.stderr)
        return 64
    artifact = artifact if artifact is not None else sys.argv[0]
    failures = 0

    print(f"platform: {platform.platform()} "
          f"{platform.python_implementation()} {platform.python_version()}")
    print(f"artifact: {os.path.abspath(artifact)} (core {core.__version__})")

    resolved = shutil.which("semlf")
    if resolved is None:
        print("path: warn — semlf is not on PATH")
    elif os.path.realpath(resolved) != os.path.realpath(artifact):
        print(f"path: warn — `semlf` resolves to {resolved}, "
              "not the artifact running doctor")
    else:
        print(f"path: semlf resolves to {resolved}")

    print(_long_limit_line())
    for pattern in core.load_config(os.getcwd()).get("exclude", []):
        print(f"exclude: {pattern}")

    cmd = _artifact_command(artifact) + ["--hook", "claude"]
    bad = _pipe(cmd, BAD_PAYLOAD)
    good = _pipe(cmd, GOOD_PAYLOAD)
    if bad is None or good is None:
        print("replay: FAIL — could not run the artifact")
        failures += 1
    elif bad[0] != 2 or "fused" not in bad[1]:
        print(f"replay: FAIL — fused edit expected exit 2 with a fused "
              f"report, got exit {bad[0]}")
        failures += 1
    elif good[0] != 0:
        print(f"replay: FAIL — clean edit expected exit 0, got {good[0]}")
        failures += 1
    else:
        print("replay: ok — fused edit blocked (exit 2), clean edit passed (exit 0)")

    # One manifest snapshot for the whole run: display and classification
    # must agree, load() has already dropped invalid and unknown entries,
    # and every record is judged against the artifact's CURRENT expected
    # destination — classifying a record against its own recorded path
    # would let a hostile record vouch for an arbitrary file.
    destinations = _expected_destinations()
    for name, entry in sorted(manifest.load().items()):
        dest = destinations.get(name)
        if dest is None:
            print(f"provenance: {name} warn — no destination resolves here")
            continue
        # Guarded classification first: classify_entry snapshots through
        # the no-follow primitive before any path resolution, so no
        # realpath touches the destination until it is ruled a regular
        # file or the entry is already unrecorded.
        state = manifest.classify_entry(entry, dest)
        if state != "unrecorded":
            print(f"provenance: {name} {state} ({entry['version']})")
            continue
        if not os.path.lexists(str(dest)):
            print(f"provenance: {name} warn — recorded at {entry['path']} "
                  "but missing")
            continue
        try:
            mismatch = (os.path.realpath(str(dest))
                        != os.path.realpath(entry["path"]))
        except (OSError, ValueError):
            mismatch = False
        if mismatch:
            print(f"provenance: {name} warn — recorded for {entry['path']}, "
                  f"expected {dest}")
        else:
            print(f"provenance: {name} unrecorded ({entry['version']})")

    failures += _codex_hook_check()

    if failures:
        print(f"doctor: {failures} check(s) failed")
        return 1
    print("doctor: ok")
    return 0


def _codex_hook_check():
    """Replay a fused and a clean Codex patch through the installed hook.

    Both directions are required for an ok: a checker that exits 2 for
    everything would block clean edits and must not be certified.
    An installed hook doctor cannot certify is a FAIL, never a silent
    pass — only a genuinely absent hook contributes nothing.
    """
    home = manifest.codex_home()
    if home is None:
        print("codex hook: no home to check")
        return 0
    hooks_path = home / "hooks.json"
    if not os.path.lexists(str(hooks_path)):
        print("codex hook: not installed")
        return 0
    data = manifest.read_state_json(hooks_path)
    if data is None:
        print("codex hook: FAIL — hooks.json is unreadable, oversized, "
              "not a regular file, or not valid JSON")
        return 1
    hooks = data.get("hooks") if isinstance(data, dict) else None
    post = hooks.get("PostToolUse") if isinstance(hooks, dict) else None
    if not isinstance(post, list):
        print("codex hook: not installed")
        return 0
    owned = []
    for block in post:
        if not isinstance(block, dict) or not isinstance(block.get("hooks"), list):
            continue
        for h in block["hooks"]:
            argv = manifest.parse_managed_codex_hook(block.get("matcher"), h)
            if argv:
                owned.append(argv)
    if not owned:
        print("codex hook: not installed")
        return 0
    if os.name == "nt":
        # The installed command string carries POSIX quoting; executing
        # it through a different tokenizer would certify a guess.  An
        # installed hook we cannot replay is a failed check, not a pass.
        print("codex hook: FAIL — installed, but replay is not yet "
              "defined on this platform")
        return 1
    # The installer treats every owned entry as managed and updates all
    # of them, so certification must cover all of them too: one healthy
    # entry must not vouch for a stale or broken sibling.
    for argv in owned:
        try:
            if not stat.S_ISREG(os.lstat(argv[1]).st_mode):
                print(f"codex hook: FAIL — configured checker is not a "
                      f"regular file ({argv[1]})")
                return 1
        except OSError:
            print(f"codex hook: FAIL — configured checker missing ({argv[1]})")
            return 1
        fused = _pipe(argv, CODEX_PAYLOAD)
        clean = _pipe(argv, CODEX_CLEAN_PAYLOAD)
        if fused is None or clean is None:
            print("codex hook: FAIL — could not run the configured command")
            return 1
        if fused[0] != 2 or "fused" not in fused[1]:
            print(f"codex hook: FAIL — fused patch expected exit 2 with a "
                  f"fused report, got exit {fused[0]}")
            return 1
        if clean[0] != 0:
            print(f"codex hook: FAIL — clean patch expected exit 0, "
                  f"got {clean[0]}")
            return 1
    print(f"codex hook: ok — {len(owned)} owned entr"
          f"{'y' if len(owned) == 1 else 'ies'} certified in both directions")
    return 0
```

A final-component symlink at the configured checker is refused by the `lstat` gate before anything executes;
symlinked *parent* directories are legitimate
(a checkout may live behind one) and are not the checker's identity.
The replay then executes by pathname —
the gate is a misconfiguration check, not a security boundary,
and the window between it and the `subprocess` launch is same-user concurrency,
out of scope by ADR-0014's stated boundary.
Doctor's provenance loop touches only schema-valid entries
(`load()` already dropped anything whose path could make `realpath` raise).

`CODEX_CLEAN_PAYLOAD` sits beside the other payload constants:
the same apply_patch envelope with a single clean added line
(`+// Package cache provides caches.`).
Doctor never crashes on hostile state:
every structure it reads (manifest entries, hooks JSON levels, command strings)
is validated or delegated to a validating helper before use,
and a shape it cannot certify is a named `FAIL` or `skipped` line, never a traceback.
